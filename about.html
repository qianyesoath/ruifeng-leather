给设计师For designers

法国小牛那一手感，给设计师的参考价 Calf of that European hand, at a designer’s reference price.

广东小鞣厂，专做小牛皮，卖给独立设计师品牌。没有真实门牌，也没有客户名单。A small Guangdong mill for designer brands — calf hides, not finished bags. No street address. No client list.

这是什么厂What this mill is

锐枫皮业做小牛皮料，不是成品。给包袋、鞋、小皮件的工作室看整张皮。中国设计师和海外买手看同一本目录，只是联系方式不同：中文走微信，英文走邮件。

Ruifeng is calf hides, not finished goods. Studios making bags, shoes, or small leather look at full hides. China and overseas see the same book; contact path changes with language — WeChat in Chinese, email in English.

目录按粒面分：Togo纹、Swift纹、Epsom纹、掌纹、摔纹、小纹、光面盒纹、大纹。设计师怎么叫，页上就怎么写。

The book is by grain: Togo, Swift, Epsom, palm grain, tumbled, fine pebble, box calf, large pebble. The names are how studios search.

厂在广东。具体地址、税号、认证以后有了再补。没有证书就不写。

The mill is in Guangdong. Address, tax id, and certificates wait until they are real.

9月1日皮料展可看实样。展位号以当天现场为准。

Samples at the 1 Sept leather fair. Booth number is confirmed on the day.

下单按色号Order by color code

色号是下单依据。格式 RF-xxxx，固定不复用。名字以后可以改，同一个号永远只代表这一色。屏幕色仅供参考，以实物和色号为准。

The color code is how you order. RF-xxxx never gets reused. Names can change; the number stays. Screen color is a guide; the hide and the code decide.

怎么要一块小样How to request a swatch

  1. 在色卡或目录里记下色号（例如 RF-3002）和粒面（例如 Togo纹）。Note the color code (e.g. RF-3002) and the grain (e.g. Togo).
  2. 打开「询价寄样」，必填色号和粒面，勾选「要小样」。Open Inquiry. Color code and grain are required. Tick “I want a swatch”.
  3. 中文加微信 ruifeng-demo；英文写 hello@ruifengleather.com。展会现场直接说色号即可。Chinese: WeChat ruifeng-demo. English: hello@ruifengleather.com. At the fair, just say the code.
  4. 本站不会真的寄出，只在这台电脑记下草稿。This site does not mail anything. It only saves a draft on this computer.

怎么合作How we work

先看皮，再寄小样，然后按张、按厚度谈参考价。没有网店库存，也不按批发档报价。给独立设计师品牌自己下料用。

Look at the hide, ask for a swatch, then we quote by piece and thickness. No webshop stock. No wholesale tiers. Made for independent designer brands cutting their own work.

不会写在这站上的东西What this site will not claim

  • 不写真实客户，不写任何品牌供货关系。No real clients. Do not claim any brand supply relationship.
  • 不卖成品，不接购物车，不收款。No finished goods, no cart, no payment.
  • 价不是商城价，是参考价，谈完再定。Prices are reference, not a webshop list.
